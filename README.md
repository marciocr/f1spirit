f1spirit
====

F1 Spirit Remake is an unofficial, not-for-profit remake of Konami's F1
SPIRIT: The Way to Formula-1. It was originally released for the MSX home
computer, and this version was presented to the Retro-Remakes competition
2004, finishing 13th out of 73 entries.

This build targets desktop Linux (x86_64) with SDL3 and OpenGL. See
[INSTALL](INSTALL) for dependencies and build instructions.

The original readme (with detailed how to play) can be found [here](readme.txt)
